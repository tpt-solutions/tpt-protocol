# Changelog

All notable changes to this crate are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this crate uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-01

### Added
- Initial release: From-scratch EtherCAT implementation (alternative to the ethercrab crate).

### Changed
- Renamed from `out-protocol-ethercat`. Publishing is enabled. The parser is still from scratch, not a wrapper around `ethercrab`.
