# Contributing to TPT Protocol

Contributions are accepted as **issues only**. Please open an issue to report a
bug, ask a question, or propose a change. Pull requests are not accepted, so
please do not open one.

- **Bug reports:** use the bug report template. Include the crate and version (or
  commit), the input bytes or test case that shows the problem, and what you
  expected.
- **Feature or protocol requests:** describe the protocol or use case and link to
  its specification where one exists.
- **Questions:** open an issue and label it as a question.
